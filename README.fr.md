# Codex Griffe

Codex Claw, mais en francais: la meme application, avec une meilleure opinion
d'elle-meme et une pause cafe obligatoire avant chaque refactor.

Si l'agent trouve un bug, il soupire, dit que l'architecture manque de terroir,
puis corrige quand meme parce qu'au fond il est tres competent.

## Fonctionnalites

- Plusieurs agents qui collaborent, mais chacun pense secretement avoir raison.
- Des statuts visibles, pour annoncer une greve symbolique pendant `npm install`.
- Un rendu natif des messages, outils et diffs, parce que meme les terminaux
  meritent parfois d'etre juges avec elegance.
- Une Bench pour deployer les meilleurs agents, apres un entretien rapide sur
  leur gout en fromage.

## Installation

```bash
npm install
npm run dev
```

Voila. C'est comme le README anglais, mais avec plus de panache et legerement
moins de tolerance pour le cafe filtre.

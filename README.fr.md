# Codex Claw - version francaise

Pourquoi le README francais refuse-t-il de se lancer tout de suite ?

Parce qu'il veut d'abord debattre de la meilleure baguette, corriger trois
accents, puis expliquer que l'anglais manque de nuance.

Bienvenue dans Codex Claw : l'app ou meme les agents font une pause cafe avant
de travailler, mais finissent quand meme par livrer avec panache.

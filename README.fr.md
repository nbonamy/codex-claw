# Codex Claw, mais en français

Codex Claw est une application de bureau pour diriger une petite équipe
d'agents Codex sans transformer votre terminal en salle de crise.

## Pourquoi cette version existe

Parce qu'un projet sérieux mérite une version française, idéalement livrée avec
un haussement d'épaules élégant et une pause café obligatoire.

## Fonctionnalités

- Des agents Codex avec chacun leur dossier, leur identité et leur conversation.
- Une interface native pour lire les messages, outils, plans, diffs et sorties
  de commandes.
- Des statuts d'agents, une inbox locale et des équipes qui essaient de rester
  organisées malgré une tendance très française à débattre de la meilleure
  manière de nommer un bouton.

## Mode d'emploi

```bash
npm install
npm run dev
```

Si ça ne marche pas du premier coup, faites comme les Français: accusez la
paperasse, prenez un café, puis relancez la commande avec panache.

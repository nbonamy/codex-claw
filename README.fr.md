# Codex Claw

Bienvenue dans Codex Claw, l'application de bureau pour travailler avec une
équipe d'agents Codex sans vivre dans un terminal toute la journée.

## Blague française obligatoire

Pourquoi un développeur français refuse-t-il de lancer `npm test` ?

Parce qu'avant de vérifier si le code marche, il faut d'abord débattre
pendant vingt minutes pour savoir si le café est acceptable.

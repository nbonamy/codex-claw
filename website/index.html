01 / The operator inbox

See the whole queue.
Act on the part that matters.

The new Cockpit is a backlog-first view across every connected repository. It turns a noisy list of tickets into a live picture of what is unowned, in progress, blocked, or ready for you.

01
⌘

One inbox, every repo

Move between All, Backlog, WIP, and Focus. Filter by repository, assignee, or label without losing the shape of the work.

02
↗

Select once. Fan out.

Pick several issues and launch them together. Claw creates a clearly named background agent for each one—no repetitive setup dialogs.

03
⑂

Isolation by default

Every assignment gets its own branch and worktree. Existing branches are reused safely, and your current workspace stays uninterrupted.

02 / Parallel by design

From “we should fix that”
to three agents working.

Claw keeps the human at the decision points and automates the mechanical ones. Choose the work and the team; it handles names, prompts, branches, worktrees, and background launch.

3×

More throughput, not more tabs.
Each agent keeps its own conversation, context, files, browser, and status.

  1. 01
    Triage the signal

    Open Focus for blockers and review-ready work, or Backlog to choose what starts next.

  2. 02
    Choose Investigate or Fix

    Send the selected issues to the right team with one confirmation.

  3. 03
    Let the team run

    Named agents work in parallel while Cockpit tracks ownership and lifecycle.

  4. 04
    Review the edges

    Jump in for a blocker, inspect the diff, or open the agent that is ready for review.

03 / Git, all the way through

The handoff doesn’t
stop at the code.

Review exactly what changed, then commit, push, create a draft pull request, or merge from the same agent workspace. Claw keeps branch and worktree lifecycle visible instead of hiding it behind automation.

  • Ask Codex to draft commit and PR copy
  • Merge, squash, push, and retry safely
  • Clean up linked worktrees without losing the agent

# Korus Project Skills

Project-specific Codex skills for Korus live under `.agents/skills/`.
Each skill has its own `SKILL.md` with `name` and `description` frontmatter and
should stay concise, procedural, and specific to this repository.

## Skills

- `korus-dod`: Definition of Done before handoff, commit, push, or calling
  work complete.
- `korus-frontend-dev`: Vue, Element Plus, app shell, chat rendering,
  artifact panes, design tokens, themes, and frontend tests.
- `korus-live-preview`: Isolated, parallel-safe, branch-faithful web
  previews for interactively dogfooding any Korus feature.
- `korus-testing-coverage`: Vitest, component isolation, IPC contracts,
  fake Codex transports, coverage triage, and verification gates.

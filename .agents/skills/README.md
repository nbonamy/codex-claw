# Codex Claw Project Skills

Project-specific Codex skills for Codex Claw live under `.agents/skills/`.
Each skill has its own `SKILL.md` with `name` and `description` frontmatter and
should stay concise, procedural, and specific to this repository.

## Skills

- `codex-claw-dod`: Definition of Done before handoff, commit, push, or calling
  work complete.
- `codex-claw-frontend-dev`: Vue, Element Plus, app shell, chat rendering,
  artifact panes, design tokens, themes, and frontend tests.
- `codex-claw-testing-coverage`: Vitest, component isolation, IPC contracts,
  fake Codex transports, coverage triage, and verification gates.
